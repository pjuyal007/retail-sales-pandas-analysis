# 📊 Retail Sales Analysis using Pandas

## 📌 Overview
This project performs data cleaning, transformation, and exploratory data analysis on a retail dataset using Pandas. The objective is to extract meaningful business insights related to sales, customers, and product performance.

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📊 Analysis Performed

### 🔹 Data Cleaning
- Handled missing values and duplicates
- Converted data types for proper analysis

### 🔹 Feature Engineering
- Extracted Year and Month from order date
- Created profit categories (Profit/Loss)

### 🔹 Exploratory Data Analysis
- Sales distribution across categories
- Customer-wise revenue analysis
- Region-wise performance
- Product-level insights

### 🔹 Advanced Analysis
- Running total of sales
- Customer ranking based on spending

## 🔥 Key Insights
- Technology category generates highest sales
- A small group of customers contributes major revenue
- Some products generate losses despite high sales
- Sales and profit are not always directly correlated
- Certain customers show repeat purchase behavior
